# Good Foods Business desktop app downloads

This repository only hosts the installers of **Good Foods Business**, the desktop app for shops that sell on [Good Foods](https://goodfoods.app): the shop portal in its own window, with order alerts that ring on the counter computer (Mac and Windows). There is no code here. Download the app from [goodfoods.app/business/desktop](https://goodfoods.app/business/desktop) or from the latest release on this page, and write to hello@goodfoods.app for help.
